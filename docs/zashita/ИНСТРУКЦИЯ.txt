Что в архиве
  ИНСТРУКЦИЯ.txt                     — этот файл
  Установить_всё.bat                 — запускает установку всего нужного
  install.ps1                        — сам скрипт установки (запускается из .bat)
  WardClick.sql                      — база данных для SQL Server
  WardClick-*-x86_64.apk             — приложение для эмулятора Android Studio
  WardClick-*-arm64-v8a.apk          — приложение для телефона
  WardClick-*-source.zip             — проект для Android Studio (с ключом Яндекс Карт)
  Пояснительная_записка.docx / .pdf  — пояснительная записка

Требования к компьютеру
  - Windows 10 (версия 1809 и новее) или Windows 11, 64 бит;
  - права администратора;
  - интернет: будет скачано около 8–10 ГБ;
  - оперативная память — от 8 ГБ (лучше 16 ГБ), свободное место — от 30 ГБ;
  - для эмулятора в BIOS должна быть включена виртуализация (Intel VT-x или AMD-V).

Готовьте компьютер ЗАРАНЕЕ, а не в день защиты: установка и первая
сборка проекта занимают 1–1,5 часа.


ШАГ 1. Распаковать архив
  Правой кнопкой по архиву → «Извлечь всё…» → укажите папку C:\WardClick
  → «Извлечь». Файлы из списка выше должны лежать прямо в C:\WardClick.
  Не запускайте файлы изнутри архива, не распаковав его.
  Путь — только латиницей, без пробелов: Android Studio плохо работает
  с русскими буквами в пути.

ШАГ 2. Установить программы и создать базу
  Нажмите правой кнопкой на «Установить_всё.bat» → «Запуск от имени
  администратора». Скрипт сам:
    1) установит Android Studio, SQL Server 2022 Express,
       SQL Server Management Studio 22 и утилиту sqlcmd
       (с официальных сайтов, через встроенный в Windows winget);
    2) создаст базу данных WardClick из файла WardClick.sql;
    3) распакует проект в C:\WardClick\project.
  Если скрипт пишет, что не найден winget, — установите из Microsoft Store
  приложение «Установщик приложений» (App Installer) и запустите .bat снова.
  Если какая-то программа не установилась, запустите .bat ещё раз:
  уже установленное скрипт пропустит.

ШАГ 3. Первый запуск Android Studio
  1) Запустите Android Studio, выберите «Standard» и примите лицензии —
     среда скачает Android SDK (около 3 ГБ).
  2) File → Open → C:\WardClick\project\WardClick → «Trust Project».
  3) Дождитесь окончания Gradle Sync (первый раз 10–20 минут). Если внизу
     появится предложение установить недостающую платформу SDK
     (Install missing platform / build tools) — нажмите и согласитесь.

ШАГ 4. Эмулятор и запуск приложения
  1) Справа «Device Manager» → «+» → «Create Virtual Device» → Pixel 8 →
     образ системы API 35, x86_64 (нажмите Download) → Finish.
  2) Запустите эмулятор кнопкой ▶ в Device Manager.
  3) Запуск приложения: зелёная кнопка ▶ «Run 'app'» в Android Studio
     или перетащите файл WardClick-*-x86_64.apk мышкой в окно эмулятора.
  Приложение работает в демонстрационном режиме: сервер и SQL Server ему
  не нужны. Интернет нужен только для карты.
  Вместо эмулятора можно показать на телефоне: скопируйте на телефон
  WardClick-*-arm64-v8a.apk, откройте его и разрешите установку.

ШАГ 5. База данных в SQL Server Management Studio
  1) Запустите SSMS. Server name: .\SQLEXPRESS
     Authentication: Windows Authentication, отметьте
     «Trust server certificate» → Connect.
  2) Databases → WardClick → Tables — 13 таблиц с данными.
  3) Диаграмма: правой кнопкой на «Database Diagrams» → «New Database
     Diagram» → выделите все таблицы → Add.
  Если база не появилась: File → Open → File → C:\WardClick\WardClick.sql
  → Execute (F5), затем правой кнопкой на «Databases» → Refresh.

Перед защитой
  - Заранее запустите эмулятор (первый запуск долгий) и откройте приложение.
  - Вход: user@wardclick.ru и admin@wardclick.ru, пароль 123456.
  - Панель администратора: в профиле 10 раз нажать «Версия приложения».
  - Выбирайте даты в будущем. Данные демо-режима сохраняются между
    запусками: чтобы начать с чистого листа, в эмуляторе Настройки →
    Приложения → WardClick → Хранилище → Очистить данные.

Если что-то не работает
  - Эмулятор не запускается: включите виртуализацию в BIOS, а в Windows —
    «Платформа низкоуровневой оболочки Windows» (Windows Hypervisor
    Platform) в «Включение или отключение компонентов Windows».
  - Ошибки Gradle Sync: File → Invalidate Caches → Invalidate and Restart.
  - SSMS не подключается: Win+R → services.msc → служба
    «SQL Server (SQLEXPRESS)» должна быть в состоянии «Выполняется».
  - Если ничего не помогает, приложение можно показать на телефоне
    (arm64-v8a APK), а базу — открыв WardClick.sql в любом редакторе.
