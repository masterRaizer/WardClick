# ВардКлик — мобильное приложение для бронирования жилья

Курсовой проект. Приложение в стиле Airbnb/Agoda: поиск жилья по городу, датам и гостям, карта Яндекса, бронирование, отзывы, избранное и панель администратора.

**Стек:** Kotlin, Jetpack Compose (Material 3), Navigation Compose, ViewModel + StateFlow, Retrofit/OkHttp, Coil, Yandex MapKit; модели и утилиты — на Java. minSdk 26, targetSdk 35.

## Запуск
1. Откройте проект в Android Studio, дождитесь Gradle Sync.
2. Запустите конфигурацию `app` на эмуляторе или телефоне.

По умолчанию включён **демо-режим** (`USE_MOCK = true` в `app/build.gradle.kts`): сервер не нужен, данные хранятся на устройстве.

Тестовые аккаунты (на экране входа есть кнопки автозаполнения):

| Роль | Email | Пароль |
|---|---|---|
| Пользователь | user@wardclick.ru | 123456 |
| Администратор | admin@wardclick.ru | 123456 |

## Яндекс Карты
1. Получите ключ **MapKit Mobile SDK** в кабинете разработчика: https://developer.tech.yandex.ru
2. Добавьте в файл `local.properties` (в корне проекта, в git он не попадает):
   ```
   MAPKIT_API_KEY=ваш_ключ
   ```
3. Нажмите **Sync Project with Gradle Files** и запустите приложение заново.

Без ключа приложение работает, а вместо карты показывается подсказка. С ключом на вкладке «Поиск» переключатель **Список / Карта** показывает маркеры с ценой за ночь; нажатие на маркер открывает карточку с кнопками «Подробнее» и «Забронировать». На экране объекта есть мини-карта и кнопка «Открыть в Яндекс Картах».

## Правила бронирования
- Статусы: ожидает подтверждения → подтверждено (администратором) → отменено; «завершено» вычисляется по дате выезда.
- Даты не должны пересекаться с активными бронями (PENDING/CONFIRMED) — иначе ошибка 409.
- Не более 30 ночей, число гостей не больше вместимости, прошедшие даты недоступны.
- Итоговая цена = ночи × цена за ночь, считается на стороне «сервера».
- Один отзыв на одно завершённое проживание.

## Реальный сервер
Для работы с REST API (Spring Boot + MS SQL) установите `USE_MOCK = false` и укажите `BASE_URL` в `app/build.gradle.kts` (`10.0.2.2` — localhost компьютера из эмулятора).
